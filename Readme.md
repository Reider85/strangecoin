Описание реализации
Блокчейн и консенсус:
Блокчейн хранит блоки с транзакциями и балансы кошельков.
Используется механизм консенсуса Proof of Work: для добавления блока требуется найти хэш, начинающийся с заданного количества нулей (сложность = 2).
Транзакции проверяются на наличие достаточного баланса перед добавлением в блок.
Механизм поиска в сети:
Метод discover_peers имитирует поиск узлов, добавляя их IP-адреса в список peers. В реальной сети можно использовать UDP-бродкаст.
Узлы синхронизируют блокчейны, запрашивая данные у других узлов через TCP-соединение.
Поиск кошелька по IP:
Метод find_wallet_by_ip возвращает адрес кошелька, связанного с IP, если узел найден в списке пиров. Для простоты используется случайный выбор из тестовых кошельков.
Клиент:
Реализован с использованием библиотеки eframe (GUI на основе egui).
Содержит поля для адреса кошелька, баланса, ввода получателя и суммы для перевода, а также кнопку для отправки транзакции.
Поддерживает аутентификацию (простая проверка пароля "password").
Клиент запускается локально на разных портах (например, 8081 и 8082).
Аутентификация:
Пользователь вводит адрес кошелька и пароль. Для простоты пароль фиксированный ("password").
После успешной аутентификации открывается интерфейс для работы с кошельком.
Тест:
Тест test_two_clients запускает два клиента на портах 8081 и 8082.
Каждый клиент инициализируется с разными адресами кошельков (wallet1 и wallet2).
Проверяется обнаружение узлов и синхронизация блокчейнов.
