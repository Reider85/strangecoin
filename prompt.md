# 117 промптов для Этапа 0 Strangecoin (Санация прототипа)

Каждый промпт — самостоятельное задание для ИИ-агента (opencode/Codex/Claude и т.п.).
Порядок выполнения: разделы идут по зависимостям (сначала криптография → сериализация →
консенсус → хранение → сеть). Внутри раздела промпты можно выполнять последовательно.

Общий контекст для всех промптов (добавлять к каждому заданию):

```
Репозиторий Strangecoin, Rust. Монолит src/main.rs (1756 строк) + src/wallet.rs.
Код компилируется: cargo check — без ошибок, ~20 warning'ов.
Тип Transaction { id, sender, receiver, amount: u64 } (main.rs:52-58).
Тип Block { index, timestamp, transactions, previous_hash, hash, nonce } (main.rs:41-49).
Blockchain: { chain, balances: HashMap<String,u64>, difficulty, pending_transactions, db: LevelDB }.
Кошелёк: src/wallet.rs, Ed25519 (ed25519-dalek 2.2), keystore зашифрован PBKDF2+AES-256-GCM.
Правила: не добавлять комментарии в код без необходимости; стиль проекта — println! в
функциях, serde, rusty_leveldb. После каждого задания: cargo check и cargo test.
Ничего не коммитить без явной просьбы.
```

Сокращения: КГ = «критерии готовности».

### P003. Верификация подписи при приёме транзакции
**Промпт:** В `Blockchain::add_transaction` (main.rs:548) добавь обязательную проверку:

используй `VerifyingKey` из ed25519-dalek. Coinbase-транзакция (награда за блок) НЕ
принимается через `add_transaction` вообще — она существует только как результат
майнинга в блоке (см. P116) и проверяется в `validate_chain`. `add_transaction` должен
явно отклонять любую `is_coinbase == true`.

**КГ:**
