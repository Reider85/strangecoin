В методе new структуры Blockchain была
добавлена логика инициализации начальных 
балансов для кошельков при создании новой 
базы данных (если база данных ещё не 
существует, т.е. balances_opt равно None).
Конкретно, в случае отсутствия сохранённых 
балансов в LevelDB, теперь проверяется файл 
конфигурации (config.json), и для адреса кошелька,
указанного в конфигурации, устанавливается начальный
баланс в 10000 единиц.
