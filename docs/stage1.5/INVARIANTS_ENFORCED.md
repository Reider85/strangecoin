### Registering notes (S1.5-P18)

- **№15, №18** — впервые enforce-нуты в Stage 1.5 (deferred Stage 1 → enforced): №15 двумя проверками в `block_executor` (pre-execution reservations + post-execution receipts burn) поверх per-tx metering; №18 — `Receipt` на каждый tx в `apply_block` + derived-data rebuild + receipts sub-trie.
- **№19** — extension: enforcement-место не изменилось (`root_after`/`validate_and_apply`/stateless verify), но coverage расширен — `ContractAccount.storage_root` входит в account leaf, поэтому смена contract storage меняет глобальный state root (S1.5-P15). Verkle/KZG по-прежнему deferred (ADR-0006 amended, Stage 3+).
- **№4** — round-trip расширен: `State` PartialEq и unapply покрывают `contract_storage`; Create/Call undo — `unapply_call_storage`/`unapply_create`.
- **№20** — gas-половина формулы (`gas_used <= block_gas_limit`) enforced через №15; fee-split (`fee_burned + fee_to_miner = total_fees`) тривиален при fee=0 (degenerate); fee market — Stage 5.
- **S1.5-FBP08 re-audit (2026-10-20)** — 22/22 enforced, no regressions после S1.5-FBP03..FBP07: расширение coverage у №4 (constructor + nested value undo chain, lazy storage deep-copy), №5 (header canonical bytes v7), №8 (genesis rebuild), №11 (constructor nonce++), №15 (`Create.gas_limit` reservation), №18 (`receipts_root` в header + light-client proofs + value_transfers trail), №19 (`receipts_root` validation + TLA+ `ReceiptsRootMatch`). Residual-риски Stage 2+ — `docs/stage1.5/RESIDUAL_RISKS_STAGE2_PLUS.md`; threat residuals V-18/V-19/V-21 — `docs/stage1.5/THREAT_MODEL_STAGE1_5.md` §2.
